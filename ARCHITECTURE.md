# Architecture

> Generated by codebase-mapper on 2026-10-07

## Overview
The project is an AI-powered Sales CRM & Automation SaaS, structured as a monorepo using pnpm workspaces. It consists of a Node.js/Express backend (`apps/api`) and a React/Vite frontend (`apps/web`).

## System Diagram
```
[Frontend (React/Vite)] <---> [Backend (Express/Node.js)] <---> [Database (Prisma/PostgreSQL)]
                                     |
                                     +---> [Webhooks (External Integrations)]
                                     +---> [Socket.io (Real-time)]
```

## Components

### API Backend (`apps/api`)
- **Purpose:** Handles business logic, database interactions, external integrations (webhooks), and real-time communication.
- **Dependencies:** Express, Prisma, Socket.io, Zod (implied).
- **Key Modules:** Auth, Leads, Deals, Webhooks, WhatsApp, Integrations.

### Web Frontend (`apps/web`)
- **Purpose:** Provides the user interface for CRM management, dashboard, and automation configuration.
- **Dependencies:** React, Vite, Tailwind CSS, Radix UI, React Hook Form, Recharts.
- **Key Modules:** Dashboard, Leads, Deals, Settings, Workflows, WhatsApp.

## Data Flow
1. **Frontend:** User interacts with UI, triggers API calls via Axios.
2. **Backend:** Express routes process requests, interact with Prisma ORM to query/mutate data.
3. **Webhooks:** External services (IndiaMart, JustDial, etc.) send data to dedicated webhook endpoints.
4. **Real-time:** Socket.io facilitates real-time updates (e.g., chat).
